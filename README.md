# Homestead Realty

A responsive, multi-page real estate website concept for Homestead Realty, a fictional agency based in Lagos, Nigeria.

## Pages
- Home: featured listings, search, categories, brand story and testimonial.
- Properties: interactive search, category, location, price filters and sorting.
- Property details: gallery, amenities, pricing and WhatsApp/email enquiries.
- About: company story, mission, vision and values.
- Contact: contact details, enquiry form and WhatsApp/email actions.

## Run locally
Open index.html in a browser, or serve the project with any static file server. No build step or paid dependency is required.

## Deploy to Cloudflare Pages
Connect this GitHub repository to a Pages project. Use None as the framework preset, leave the build command empty, and set the build output directory to /.

## Notes
Property listings and testimonials are illustrative demo content, not verified live inventory or customer endorsements. Replace them with approved client data before production. The contact form opens the visitor's email client; no backend or data storage is configured. Replace the sample developer-credit link in assets/app.js with the confirmed portfolio URL.
